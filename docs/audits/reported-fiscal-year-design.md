# Reported fiscal years alongside the strict calendar audit

The existing 336-cell audit asks for January 1–December 31 2023, 2024, and 2025, plus LTM. Its values, statuses, validator, and valuation denominators are unchanged. The separate **Reported fiscal years** table asks a different question: what did the issuer report for its fiscal year ending in 2023, 2024, or 2025? Every displayed FY value carries its actual start and end dates. Intel's 52/53-week annual periods, FuelCell's October year end, Micron's August year end, and IREN and Microsoft's June year ends therefore remain distinguishable from calendar years.

`buildReportedFiscalYears` runs on the same canonical observations in both the live financial builder and the audit. It accepts an exact annual period only when its boundaries are source-backed, its value is finite, its currency is USD, and the observation is SEC-sourced or the Fiscal.ai value reconciles to an exact SEC observation. An uncorroborated provider row, inferred boundary, or material source conflict stays unresolved. SEC-derived annual arithmetic is marked `VERIFIED_DERIVED`; a reported annual value is marked `VERIFIED_REPORTED`. Fiscal Free Cash Flow can be constructed only from exact-period, equal-scope operating cash flow and cash Capex. Fiscal Adjusted EBITDA comes only from selected, structurally valid SEC-filed company reconciliations; generic EBITDA and estimates are excluded.

The FY table does not write to the calendar metrics, multiples, or audit records. Existing snapshots may not yet contain the new FY array; it is generated during the existing controlled financial refresh and then retained in that row's snapshot. This branch does not run that refresh against production Supabase.

## No Fiscal.ai production subscription

The current API defaults to `FISCAL_AI` for a controlled financial refresh. Without production Fiscal.ai REST access, that refresh fails closed and retains existing snapshots. `FINANCIAL_HISTORY_PROVIDER=WISESHEETS` selects the already implemented WiseSheets acquisition path, which still obtains SEC CompanyFacts and filings and uses the same canonical period engine. It requires a valid `WISESHEETS_API_KEY`, SEC access, and the existing snapshot store configuration. This is a deployment configuration option, not an automatic unreviewed provider switch. The review branch uses preserved Fiscal.ai fixtures and makes no live Fiscal.ai request. Neither provider may supply a fiscal-year value to a January–December column solely by matching the year label.

## Remaining source work

- [IREN's December 2024 interim financial statements](https://www.sec.gov/Archives/edgar/data/1878848/000187884825000009/iren-20241231_d2.htm), accession `0001878848-25-000009`, include December 2023 comparative revenue and operating expense lines but do not state Gross Profit or a complete Cost of Revenue subtotal. Electricity, site, depreciation, and other expense lines cannot be relabeled as Cost of Revenue without an explicit accounting definition. CY2023/CY2024 Gross Profit therefore remains unresolved pending another exact-period primary source and definition check.
- The separate IREN FY Gross Profit figures **are** exactly derivable from matched SEC annual Revenue and Cost of Revenue: FY2023 $75.509M − $39.419M = **$36.090M**, using [accession 0001878848-25-000063](https://www.sec.gov/Archives/edgar/data/1878848/000187884825000063/iren-20250630.htm); FY2024 $187.192M − $87.067M = **$100.125M**; and FY2025 $501.023M − $158.992M = **$342.031M**, using [accession 0001878848-26-000052](https://www.sec.gov/Archives/edgar/data/1878848/000187884826000052/iren-20260630.htm). These June-ended FY values do not establish either January–December Gross Profit amount.
- [NBIS's 2025 Form 20-F](https://www.sec.gov/Archives/edgar/data/1513845/000110465926052948/nbis-20251231x20f.htm), accession `0001104659-26-052948`, reports $401.9 million continuing-operation OCF and $(17.1) million discontinued-operation OCF, totaling $384.8 million. The locally extracted annual cash Capex observation is $4.066 billion with `UNSPECIFIED` operation scope. Thus $401.9 million minus $4.066 billion is **not** a verified continuing-operation FCF construction. A provider total and a continuing-operations OCF value cannot be treated as equivalent; FCF needs proven matching operation scope.
- A missing company-defined Adjusted EBITDA value remains unresolved until the relevant filing inventory and reconciliation search are demonstrably complete. An absence from a capped set of filings is not positive evidence of non-disclosure.
